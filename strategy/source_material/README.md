# Source Material – Bastian Keller / TradeMania / Bitbull

Dieser Ordner ersetzt bewusst jedes strategiespezifische Material anderer Trading-Projekte.

Hier werden ausschließlich **rechtmäßig veröffentlichbare** Referenzen für die BTK-Strategie abgelegt, zum Beispiel:

- eigene Notizen zur verwendeten Indikatorversion;
- Settings-Snapshots in veröffentlichbarer Form;
- Hash-/Evidence-Referenzen;
- eigene Golden-/Black-Box-Testbeschreibungen;
- Links und Metadaten zu offiziellen TradeMania-/Bitbull-/Bastian-Keller-Quellen.

Nicht hier ablegen:

- Login-Daten oder Sessiontokens;
- vollständige geschützte Member-Inhalte/Transkripte;
- proprietären Indikator-Source ohne Veröffentlichungsrecht;
- Dateien oder Regeln aus anderen Trading-Strategien als normative BTK-Quelle.

Normative technische Wahrheit wird nach der Analyse in `DMS/03_STRATEGIE_BITBULL_TRADEMANIA_BASTIAN_KELLER.md` eingefroren.
